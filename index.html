MultiPost Local

MultiPost Local is a personal desktop tool that runs only on its owner's own Windows PC. It uploads the owner's own videos to the owner's own YouTube, Bilibili, Instagram and X accounts, and reads view counts of those videos so the owner can keep notes about how they performed.

MultiPost Local は、作者本人のWindowsパソコンだけで動く個人用の投稿ツールです。 本人の動画を本人のアカウントへ投稿し、その動画の再生数などを読み取って記録します。

It is not offered to other users. / ほかの人には提供していません。
